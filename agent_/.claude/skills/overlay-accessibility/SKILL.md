# Overlay and Accessibility

Treat overlays and AccessibilityService automation as sensitive capabilities.

Verify manifest entries, exported flags, service metadata, overlay permission, accessibility enablement, notification controls, consent explanation, enable/disable flow, denial behavior, restart behavior, and safe fallback.

Use semantic targets with confidence and rationale. Apply bounded timeouts and post-action verification. Do not bypass Android permission/consent, automate hidden interactions, read unnecessary sensitive content, or take consequential actions without the required user confirmation.
